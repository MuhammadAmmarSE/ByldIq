# TechnologyStrengthsWeaknesses

CLAUDE.md Part 22's Strengths and Weaknesses sections, rendered side by
side with equal visual weight.

## Honesty over hedging

Part 22 is explicit: "Weaknesses: Honest... Every technology has
weaknesses. Transparency builds trust." Weaknesses use the same list
styling as strengths (label + description, same typography) rather than
being softened, shortened, or visually deprioritized.

## Heading hierarchy

Each section title renders as `<h2>` (`Heading variant="h3" as="h2"`) —
`TechnologyDetailHero`'s headline owns the page's `<h1>`.

## Stable ids

`#strengths` and `#weaknesses` are kept for the sticky sidebar/scrollspy
a later phase adds.
