# CaseStudyProductThinking

CLAUDE.md Part 21's Product Thinking section: `productDecisions`
(`{decision, reasoning, tradeoff}[]`) and `rejectedIdeas` grouped into one
component, since both describe the same underlying activity — deciding
what to build and what not to.

## Why trade-offs sit next to each decision

CLAUDE.md Part 3 treats honest trade-offs as part of the story, not a
caveat tucked away elsewhere — every decision card shows its trade-off
immediately below the reasoning, not in a separate "risks" list.

## Heading hierarchy

The section title renders as `<h2>` (`Heading variant="h3" as="h2"`); the
"What we deliberately left out" sub-heading renders as `<h3>`
(`Heading variant="h6" as="h3"`).
