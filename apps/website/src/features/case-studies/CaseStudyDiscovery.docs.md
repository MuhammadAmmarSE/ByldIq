# CaseStudyDiscovery

CLAUDE.md Part 21's Discovery section: the research and stakeholder work
that informed the eventual product strategy, rendered as a card grid
(`caseStudy.discovery: {title, description}[]`) rather than a text list to
visually separate it from the surrounding paragraph-only sections
(CLAUDE.md Part 5: "cards communicate grouping").

## Heading hierarchy

The section title renders as `<h2>` (`Heading variant="h3" as="h2"`); each
activity title renders as `<h3>` (`Heading variant="h6" as="h3"`).
