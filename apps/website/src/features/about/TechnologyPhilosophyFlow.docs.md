# TechnologyPhilosophyFlow

CLAUDE.md Milestone 13 §12's Technology Philosophy — deliberately not a
second Technology Explorer, per the spec's own instruction. Explains
_how_ Byld IQ chooses technology (a funnel of real constraints — business
requirements, product constraints, team capability, performance,
scalability, security, cost — narrowing to one decision) and links out to
the real Technology Explorer (CLAUDE.md Part 22, `/technology`) for the
_what_, where every individual technology's trade-offs already live.
