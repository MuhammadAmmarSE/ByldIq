# KnowledgeRealExamples

CLAUDE.md Part 18's Real Examples section: concrete, fictional scenarios
(`article.realExamples`) that make the article's core concepts tangible —
the same "believable fictional data, not Lorem Ipsum" approach the
homepage's Product Showcase uses (CLAUDE.md Part 14).

## Heading hierarchy

The section title renders as `<h2>` (`Heading variant="h3" as="h2"`); each
example's title renders as `<h3>` (`Heading variant="h5" as="h3"`) — the
same "smaller visual size, correct document order" pattern
`ProjectCard`/`TechnologyCard` use inside a grid.
