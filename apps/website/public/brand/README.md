# public/brand/

The single source of truth for the Byld IQ logo, icon, and wordmark
(CLAUDE.md Part 28: Brand Asset Governance). Every logo appearance on the
site — navbar, footer, favicon, loading states, the Arrival Experience,
OG images, and any future product surface — references a file in this
folder. Nothing gets its own hand-drawn or procedurally generated
version.

## Status

Empty. No official assets have been added to the repository yet.

Until a real file lands here, any code that needs the Byld IQ mark must
either be deferred or must clearly ask for the asset — never fabricate a
stand-in shape and ship it, even temporarily.

## Expected files (add here when available)

- `byldiq-icon-master-transparent.svg` — the master icon mark, the
  primary source for the Arrival Experience and any icon-only usage.
- `byldiq-wordmark.svg` — the full "Byld IQ" wordmark, if distinct from
  the icon.
- `byldiq-icon.png` / other raster exports — for contexts that require a
  raster format (e.g. `favicon.ico` generation, OG image fallback).

Adjust this list to match whatever the designer actually delivers; the
point is that whatever lands here becomes the one and only reference for
that asset going forward.
