# KnowledgeExecutiveSummary

CLAUDE.md Part 18's Executive Summary section: who the article is for
(`article.audience`) and what a reader will learn
(`article.learningOutcomes`) — helping visitors decide whether to keep
reading before investing the article's full reading time. The title and
one-sentence summary already live in `KnowledgeArticleHero`, so this
component doesn't repeat them.

## Heading hierarchy

Each section title renders as `<h2>` (`Heading variant="h3" as="h2"`) —
`KnowledgeArticleHero`'s title owns the page's `<h1>`.
