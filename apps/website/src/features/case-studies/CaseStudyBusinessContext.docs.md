# CaseStudyBusinessContext

Milestone 12's Business Context section: the environment a project
existed in — business model, market, existing technology, competitive
pressure — shown before any technical detail (CLAUDE.md Part 12: "The
visitor should understand why the project existed before seeing
technical implementation details").

## Placement

Between Business Challenge and Discovery in the page template, matching
the order the milestone brief describes. Not in the fourteen-section
structure Milestone 5 originally shipped — a genuinely new section, not
a restyle of an existing one.

## Data

`caseStudy.businessContext` — a required, four-field object
(`businessModel`, `market`, `existingTechnology`,
`competitivePressure`) populated for all five case studies in
`data/case-studies.ts`. Every field is real, specific narrative grounded
in each fictional company's already-established facts (CLAUDE.md Part 14) — never generic placeholder text.
