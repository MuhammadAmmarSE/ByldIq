# DesignEngineeringFlow

CLAUDE.md Milestone 13 §6's Design + Engineering: a purely illustrative
flow (Product Strategy → UX → UI → Design System → Architecture →
Engineering → Validation) plus a loop-back note — the note is the point.
Without it, a left-to-right row of stages reads exactly like the one-way
handoff the section explicitly argues against ("design isn't handed over
to engineering as a finished artifact").

Unlike `CaseStudyArchitecture`'s clickable pipeline, there's no
per-project detail to inspect here — every node is the same regardless of
which visitor is looking at it — so this stays a static illustration, not
an interactive explorer.
