# Content

Reserved for MDX content collections (articles, guides, case studies,
whitepapers) defined in `content-collections.ts` at the repo root. No
content types are defined yet. Milestone 3's homepage Knowledge Center
preview (`features/homepage/knowledge-center-preview/`) uses local typed
data instead — a real CMS/MDX content model is a future Knowledge Center
milestone's work, not this one's.
