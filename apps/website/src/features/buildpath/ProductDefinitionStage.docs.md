# ProductDefinitionStage

CLAUDE.md Milestone 14's Product Definition canvas. Mostly read-only —
Vision, Problem, and Target Users are pulled directly from the Discovery
and Target Users stages, never re-asked. Platforms and Constraints are
the two things this stage captures directly (`canvasExtras` in
`buildpath-store.ts`).

Key Features intentionally shows "you'll add features in the next step"
rather than fabricating placeholder features — Prioritization (the next
stage in the flow) is where those actually get added, and this stage
runs before it.
