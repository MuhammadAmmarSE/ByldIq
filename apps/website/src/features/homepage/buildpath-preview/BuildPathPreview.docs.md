# BuildPathPreview

CLAUDE.md Part 17's BuildPath, scoped to a homepage teaser rather than the
full 11-stage questionnaire (which is BuildPath-scale product surface for
a future milestone). Composes `QuestionnaireTaste` (one real, working
multiple-choice question) and `RoadmapPreview` (the design system's
`Timeline`, reused) — selecting a goal updates the roadmap's Phase 1
description live, so the "preview" is a genuine interaction, not a static
mock.

## Navigation

The CTA links to a real `/buildpath` page (a genuine "coming soon" page
explaining the vision) rather than a modal or a dead link — consistent
with the Proof Engine's case-study pages (Phase 5).
