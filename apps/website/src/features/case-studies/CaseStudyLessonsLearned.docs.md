# CaseStudyLessonsLearned

CLAUDE.md Part 21's Lessons Learned section — "the most valuable section"
per the spec: what worked, what the team would do differently, and
recommendations for teams facing a similar problem.

## Layout

Three columns (`whatWorked`, `whatCouldImprove`, `recommendations`), the
same list layout `CaseStudyOverview` uses for constraints/risks/success
criteria — kept visually consistent rather than introducing a fourth list
style on the same page.

## Heading hierarchy

The section title renders as `<h2>` (`Heading variant="h3" as="h2"`); each
column heading renders as `<h3>` (`Heading variant="h6" as="h3"`).
