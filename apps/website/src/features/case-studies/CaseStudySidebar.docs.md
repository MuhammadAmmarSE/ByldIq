# CaseStudySidebar

Sticky in-page navigation with scrollspy (CLAUDE.md Part 8), desktop
only, mirroring the Solutions Platform's `SolutionSidebar`.

## Section list

A fixed list, not derived from `CaseStudy` data — every case study page
shares the same section structure (CLAUDE.md Part 21), only the content
differs. `get-started` (the final CTA) is intentionally excluded since it
renders full-width outside the sidebar grid.

## Why desktop only

Mobile already has the bottom navigation dock; thirteen anchor links
don't fit a small viewport usefully.
