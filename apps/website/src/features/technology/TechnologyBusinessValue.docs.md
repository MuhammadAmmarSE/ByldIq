adopt it, and where it fits (business vs. engineering), grouped into one
component since none carry their own interactivity — each keeps a stable
`id` (`#business-problem`, `#why-organizations-adopt`,
`#business-and-engineering-fit`) for the sticky sidebar/scrollspy a later
phase adds.

before Byld IQ's approach" ordering as `SolutionOverview`.
