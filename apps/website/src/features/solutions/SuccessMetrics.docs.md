# SuccessMetrics

CLAUDE.md Part 20's Success Metrics: a stat grid of what "working" looks
like for this solution — four label/value pairs per solution.

## Content note

Values are qualitative where a real number can't be honestly claimed for a
prospective engagement (e.g. "Reduced vs. full-scope build" rather than
inventing a percentage). CLAUDE.md Part 7 and Part 13 are explicit that
metrics should never be fabricated — this section applies that same rule
to a category that's inherently prospective rather than a completed case
study.

Static, not interactive: there's nothing to click, unlike the other
Explorer sections on the page.
