# AiOpportunitiesStage

CLAUDE.md Milestone 14 §17: "Don't recommend AI merely because it is
fashionable." `mockAIProvider.generateAiOpportunities` can genuinely
return `relevant: false`, and this stage's default (no `AI Product`
project type, no AI-flavored features) is exactly that — an honest "no
AI recommended" card, not a forced pitch.

When AI is relevant, the assessment covers capability requirements
(RAG / agents / tool calling / vector search) plus the operational
side CLAUDE.md's engineering standards insist on for any AI feature:
evaluation, guardrails, data privacy, and human review — never shipped
as a black box.
