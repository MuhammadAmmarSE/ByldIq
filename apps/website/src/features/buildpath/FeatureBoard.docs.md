# FeatureBoard

CLAUDE.md Milestone 14 §10's Feature Discovery — manual add, plus a
four-column board grouped by `FeaturePriority`. Changing a feature's
priority (the `Select` on each card) moves it between columns directly;
there's no separate "save" step since every field writes straight to
the store.

Features added here carry `source: "user"`; features accepted from
`AiFeatureSuggestions` carry `source: "ai"` and show an "AI suggested"
badge, so the board never hides where a feature came from.
